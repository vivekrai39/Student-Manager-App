# Student Manager App

A simple Student Manager application built using Python. This project allows users to add students, view student records, and check their pass/fail results using a command-line interface.

## Features

- Add new students with their marks.
- View all registered students.
- Check individual student results.
- Automatically determine PASS or FAIL.
- Simple menu-driven interface.
- Store student information using Python dictionaries.

## Technologies Used

- Python 3
- Dictionaries
- While Loops
- Conditional Statements
- User Input
- Formatted Strings (f-strings)

## Result System

| Marks | Result |
|---|---|
| 40–100 | PASS |
| Below 40 | FAIL |
